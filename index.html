📋 軟體功能項目說明

SHL TW 目前整合八大核心模組（可由上方「功能選單」或底部導覽列一鍵切換）

  • 1
    即時行情中控台與技術圖表：追蹤自選台股與台指期（TXF），支援 Yahoo / FinMind 真實數據圖與 TradingView 進階線圖、多級距 K 線切換與國際重大金融事件標註。
  • 2
    台股技術分析 (v01) 與量化策略實驗室：10 大技術／籌碼指標開關、多 Agent 自動風控引擎，以及 30 支 Pine Script 對齊量化策略之真實歷史回測與風險指標卡。
  • 3
    台股真實回測（多階段定投 / 單筆買入）：支援多標的權重配置，可自由切換「多階段每月定期定額」或「單筆一次買入」，精算真實配息、配股、分割、減資與手續費折數，並在績效曲線標註國際重大金融事件。
  • 4
    AI 六模型與 Ollama 地端深度解析：輸入 API Token 後自動偵測可用模型並勾選（Groq / Ollama / Grok / Gemini / Claude / ChatGPT），可依自訂焦點跨標的平行交叉分析。
  • 5
    對帳單交易復盤：匯入 PDF / XLSX / CSV / JSON 對帳單或系統委託紀錄，統計勝率、獲利因子、手續費退佣與最大回撤。
  • 6
    模擬 (SIM) / 實盤 (LIVE) 下單與推播：內建紙上模擬盤與永豐金 Shioaji 實盤串接介面、TradingView Webhook 派單，以及 LINE Bot / Telegram 結構化訊號通知。
  • 7
    裝置沙盒安全保險箱與多設備連動：AES-256-GCM 本機加密、iPhone Face ID / Touch ID / 手機解鎖密碼保護，支援 AirDrop / iCloud `.shlvault`、Apple 通用剪貼簿與私有後端零知識同步。
